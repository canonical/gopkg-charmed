# gopkg

Repository for the gopkg.in service ("Stable APIs for the Go language").

The Go application, its rock and charm (built with the 12-factor
`go-framework` extensions for Rockcraft and Charmcraft), and the Terraform
deployment module will be added to this repository as the refactor
progresses.

A pre-built 12-factor scaffold is available on the `charm-scaffold` branch
for reference.
