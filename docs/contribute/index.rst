Contribute
==========

Contributions can change the documentation, the Go service, the charm, the
rock, or several of these areas. Choose the path that matches your change.

Choose a contribution path
--------------------------

Use :ref:`improve-documentation` for prose, navigation, examples, tutorials,
and how-to guides.

Use :ref:`improve-code` for the Go service, charm code, rock or charm recipes,
and integration tests.

Follow both paths when code and documentation change together, or when a
documentation command affects the running service.
